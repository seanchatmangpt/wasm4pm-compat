# ERRC v2 — Evidence-Preserving Reduction and Reconstitution

**Standing:** executable specification; hosted standing is issued only by `.github/workflows/errc-proof.yml` after exact-head execution.

**Reconstitution source:** `seanchatmangpt/ggen-legacy@60d38265b8d1d94c43f04ca6bdb8537184e510a8`.

The legacy system supplied the important operational primitives: deterministic CI evidence routing, exact-subject receipts, fail-closed standing, replay/equivalence machinery, deliberate sabotage, and the zero-information-loss law. ERRC v2 lifts those mechanisms from a routing heuristic into a falsifiable reduction theorem.

## 1. Research question

Given an admitted test/evidence set `T` and falsifier set `M`, what is the smallest deterministic subset of `T` that preserves the defect-detection and diagnostic information observed in the full experiment?

ERRC does **not** optimize for a predetermined percentage. `80/20`, `50%`, or any other ratio has no standing. Compression is an observed property of the evidence topology.

## 2. Observation algebra

ERRC admits a ternary matrix

```text
K : T × M -> {KILL, SURVIVE, UNKNOWN}
```

- `KILL`: the evidence falsifies/rejects the mutant or counterexample.
- `SURVIVE`: the evidence does not falsify it.
- `UNKNOWN`: the experiment has not established a lawful observation.

The v2 exact theorem is deliberately conservative: **any UNKNOWN cell refuses compression**. A future weaker theorem may prove that some unknown cells are irrelevant, but v2 never converts absence of evidence into evidence of equivalence.

## 3. Information obligations

The full suite induces two classes of obligations.

### 3.1 Kill preservation

For every falsifier killed by at least one original test, the retained suite must contain at least one concrete kill witness.

```text
U_kill = { m | exists t : K(t,m) = KILL }
```

### 3.2 Diagnostic preservation

For every pair of falsifiers distinguishable by the original suite, the retained suite must retain at least one test that distinguishes their observed states.

```text
U_dist = { (mi,mj) | exists t : K(t,mi) != K(t,mj) }
```

Since UNKNOWN is refused before obligation construction, diagnostic inequality is always an inequality between admitted observations.

The complete obligation universe is:

```text
U = U_kill union U_dist
```

## 4. Exact minimization theorem

For each test `t`, define `C(t) subseteq U` as the obligations witnessed by that test. ERRC searches for

```text
R* = arg min |R|
     R subseteq T
     subject to union(C(t) for t in R) = U
```

The implementation performs bounded exact branch-and-bound. It searches cardinalities from a sound coverage lower bound upward, prunes a branch when the suffix union cannot cover the remaining obligations, and enumerates test IDs in lexical order. Therefore the first solution at the minimum cardinality is the canonical lexicographically minimal solution.

If the admitted solver envelope is exceeded, ERRC returns `SOLVER_LIMIT_EXCEEDED`. It does not silently substitute a greedy approximation and retain the exact claim.

## 5. Zero-information-loss claim

Within the admitted model, a valid ERRC receipt proves:

1. every originally killable falsifier still has a retained kill witness;
2. every originally distinguishable falsifier pair still has a retained distinguishing witness;
3. the retained suite is minimum-cardinality under those obligations;
4. ties are resolved canonically;
5. every obligation is named and linked to a retained witness;
6. the theorem is bound to an exact repository and 40-hex commit SHA;
7. an independent replay reconstructs the entire receipt byte-for-byte under canonical JSON.

This is stronger than line/branch coverage preservation. Coverage can remain constant while diagnostic information is destroyed; ERRC's pairwise distinguishability obligations make that loss observable.

## 6. Receipt semantics

A receipt contains deterministic SHA-256 commitments to:

- normalized observation matrix;
- ordered test IDs;
- ordered falsifier IDs;
- obligation universe;
- retained basis;
- complete witness map;
- exact repository/head subject;
- solver algorithm and admitted limits;
- source provenance and enforced laws.

The receipt generated by `compress` deliberately carries `PARTIAL_ALIVE`: manufacture is not verification. `verify` independently reconstructs the expected receipt and returns `VERIFIED` only on exact equality. GitHub Actions then binds that replay to the checked-out `GITHUB_SHA`, runs the falsification suite, deliberately sabotages a receipt, requires typed refusal, and emits separate hosted `ALIVE` evidence for the ERRC subsystem.

Repository-wide standing remains independent; ERRC cannot erase unrelated failing gates.

## 7. Typed refusal surface

| Code | Meaning |
|---|---|
| `INVALID_MATRIX` | malformed, non-rectangular, ambiguous, or non-canonical experiment |
| `UNKNOWN_OBSERVATION` | exact evidence closure has not been established |
| `INVALID_HEAD` | subject is not bound to `owner/name` + exact 40-hex SHA |
| `SOLVER_LIMIT_EXCEEDED` | exact theorem exceeds the admitted computational envelope |
| `WITNESS_MISSING` | an admitted obligation cannot be grounded in evidence |
| `RECEIPT_MISMATCH` | digest, witness, subject, basis, matrix, or replay differs |

A refusal is a valid outcome. It prevents a weaker claim from masquerading as the exact theorem.

## 8. Falsification program

`scripts/test_errc.py` attacks the theorem rather than merely exercising happy paths:

- redundant evidence must disappear;
- unique evidence must remain;
- lexical ties must be deterministic;
- UNKNOWN must refuse;
- branch-and-bound limit overflow must refuse;
- empty information spaces must reduce to the empty basis;
- receipt mutation must refuse;
- a self-consistent attacker that recomputes witness and receipt digests must still fail independent replay;
- source-matrix mutation must fail replay;
- non-canonical IDs must refuse ambiguity.

The hosted workflow repeats manufacture and replay through the CLI, then sabotages the produced receipt and requires a non-zero typed refusal.

## 9. Boundary with wasm4pm-compat

ERRC is verification/manufacturing infrastructure. It does not introduce process-mining algorithms, runtime validation gates, or execution semantics into the structure-only Rust type foundry. This preserves the repository's compile-time type-law boundary while allowing external evidence about generated or tested artifacts to become significantly stronger.

## 10. Usage

```bash
python scripts/errc.py compress \
  --input matrix.json \
  --repo seanchatmangpt/wasm4pm-compat \
  --head <exact-40-hex-sha> \
  --output receipt.json

python scripts/errc.py verify \
  --input matrix.json \
  --receipt receipt.json \
  --output verdict.json
```

`verify` succeeds only if independent deterministic reconstruction reproduces the supplied receipt exactly.

## 11. What this does not prove

The theorem is conditional on the admitted falsifier universe. It does not claim that `M` contains every possible defect, that the observations are scientifically representative outside their admitted subject, or that pairwise diagnostic preservation captures every possible semantic objective. Those are upstream experiment-design obligations. ERRC proves that the admitted evidence was compressed without losing the detection and pairwise diagnostic information explicitly present in that experiment.

That boundary is intentional: ERRC minimizes evidence **after admission**; it does not hallucinate completeness of the world being measured.
